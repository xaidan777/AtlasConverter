# Atlas Converter

Инструмент для создания спрайт-атласов из видео и PNG-секвенций. Убирает хромакей, нарезает кадры, собирает атлас — или пакетно обрабатывает отдельные спрайты.

Установка не нужна — просто запустите `AtlasConverter.exe`.

---

## Вкладка Atlas

Для работы с видео (`.mp4`, `.avi`, `.mov`) и PNG-секвенциями.

### Загрузка

Три способа:

- кнопка **Load Media**;
- клик по пустому вьюпорту («Drop a video with animation here»);
- перетащите видеофайл, PNG-секвенцию или папку прямо на вьюпорт.

Выберите видеофайл или любой `.png` из секвенции — остальные файлы секвенции подхватятся автоматически по имени.

### Таймлайн

- **Голубые ручки по краям** — границы видео. Тяните их, чтобы обрезать диапазон кадров; рядом показан номер кадра. Ключи сжимаются или растягиваются вместе с диапазоном и сохраняют взаимное расположение — ручная расстановка не сбрасывается.
- **Ромбы внизу** — ключевые кадры, которые попадут в атлас. Кликните по ромбу, чтобы выбрать (подсветится жёлтым), и тяните мышью — превью атласа пересоберётся после отпускания. Стрелки **←/→** двигают выбранный ключ на кадр, с **Shift** — на 10.
- **Несколько ключей** — протяните мышью по нижней дорожке с ромбами: выбранные ключи окажутся в рамке. Тяните рамку — ключи сдвигаются вместе; тяните её левый или правый край — расстояния между ключами пропорционально растягиваются или сжимаются, как при перетаскивании границ диапазона. Стрелки двигают всю рамку, **Delete** удаляет выбранные ключи. Правый клик или клик в свободном месте (или **Esc**) снимает выделение.
- **Правый клик по ключу** — меню:
  - **Delete** — удалить ключ (или все выбранные);
  - **Duplicate** — копия встаёт на ближайший свободный кадр справа;
  - **Start Here** — атлас начинается с этого ключа, а всё, что было до него, уходит в конец. Место стыка отмечено зелёной пунктирной линией **START**. Чтобы вернуть обычный порядок, выберите **Start Here** на первом ключе.
- Клик по дорожке — перемотка к кадру, номер текущего кадра показан на красной метке сверху.
- **Ctrl+Z** — отменить, **Ctrl+Shift+Z** или **Ctrl+Y** — вернуть. Отменяются перестановка, удаление и дублирование ключей, Start Here, сдвиг границ, пересчёт ключей после смены **Frames** и правки Transform.
- Ключи раскладываются равномерно заново только при смене **Frames** (в том числе через **C**/**R**) и при загрузке файла (стык Start Here переезжает на ближайший ключ). Границы диапазона и **Refresh Atlas** ручную раскладку не сбрасывают.

### Воспроизведение

Панель в левом нижнем углу вьюпорта (масштаб вьюпорта показан в правом верхнем):

- **▶ / ❚❚** — воспроизведение выбранного диапазона и пауза;
- **■** — стоп и возврат к началу (или к стыку Start Here);
- **Frames** — проигрывание только ключевых кадров в порядке атласа, скорость задаётся полем **fps** рядом.

### Transform

Сдвиг и масштаб содержимого секвенции внутри кадра атласа — например, чтобы отцентровать персонажа или уменьшить его, если он не влезает в кадр.

- **Position X / Y** — сдвиг в пикселях исходного видео.
- **Scale X / Y** — масштаб в процентах. Звено между полями связывает масштаб: включено — второе поле меняется пропорционально.
- Кнопка со стрелкой сбрасывает Transform.

То же самое можно делать мышью прямо во вьюпорте — вокруг содержимого нарисована синяя рамка с ручками:

- тяните за середину рамки — содержимое сдвигается (с **Shift** — только по одной оси);
- тяните за угол или сторону — масштаб; противоположная сторона стоит на месте, с **Alt** — масштаб от центра;
- пропорции держатся, если включено звено в Transform; **Shift** во время растяжения временно переключает это;
- пока тянете, рядом с рамкой видны текущие значения, поля Transform обновляются сразу. Отмена (**Ctrl+Z**) откатывает жест целиком.

Transform применяется ко всем кадрам: во вьюпорте, в превью атласа и при экспорте. Белая пунктирная рамка — область кадра атласа, она остаётся на месте, а содержимое двигается внутри неё; опустевшие места показаны шахматкой (с Keying — цветом фона), в атласе они прозрачные.

### Хромакей (Keying)

Включите галочку **Keying** и задайте цвет фона для удаления:

- Кнопка **Key Color** — выбрать цвет вручную.
- **Пипетка** — кликните по нужному цвету прямо на превью.

Параметры:

| Параметр | Что делает |
|---|---|
| **Gain** | Допуск по оттенку — чем больше, тем шире захват похожих цветов |
| **Soften** | Размытие маски — смягчает края |
| **Clip** | Гамма-коррекция маски — сдвигает средние тона |
| **Protect Sat** | Защита ненасыщенных пикселей от удаления |
| **Protect Val** | Защита тёмных пикселей от удаления |
| **Mask** | Показать маску вместо изображения (для отладки) |

### Настройки атласа

- **W** / **H** — размер одного кадра в атласе (в пикселях).
- **C** / **R** — количество столбцов и строк в сетке.
- **Frames** — сколько кадров взять из выбранного диапазона (равномерно). При смене **C** или **R** сразу становится **C × R**, чтобы сетка была заполнена (например, 8 × 4 → 32 кадра); после этого число можно поправить вручную.

Превью атласа на правой панели пересобирается само при изменении **W/H**, **C/R** и **Frames**. **Refresh Atlas** перерисовывает превью по текущим ключам — например, чтобы применить к атласу новые настройки Keying. Расставленные вручную ключи при этом остаются на месте.

Превью интерактивное: при наведении ячейка атласа подсвечивается и подписывается номером кадра, клик по ячейке переносит курсор таймлайна на этот кадр.

### Экспорт

- **Export Atlas** — сохраняет атлас как `.png` + `.json` с метаданными (размер кадра, сетка, fps, индексы кадров в порядке атласа).
- **Export Video** — сохраняет обработанные кадры как видеофайл. Откроется окно с выбором формата (H.264, H.265, VP9, VP8, MJPEG, ProRes), битрейта и fps.

## Вкладка Sprites

Для пакетной обработки отдельных PNG-файлов.

### Загрузка

Три способа:

- кнопка **Load Files** — выберите один или несколько `.png`;
- клик по пустому вьюпорту («Drop a folder or image files here»);
- перетащите `.png` файлы или папку с ними прямо на вьюпорт.

### Навигация

Стрелки **< >** или поле с номером — переключение между загруженными файлами.

### Трансформация

Перетаскивайте спрайт мышью на превью для смещения, колесом мыши — масштаб. **Ctrl+Z** / **Ctrl+Shift+Z** — отменить / вернуть.

- **Transform All** — применить одну трансформацию ко всем файлам сразу.
- Если выключено — каждый файл запоминает свою позицию и масштаб отдельно.

### Фон

- **BG Color** — цвет фона для композиции.
- **Add Background** — включить композицию спрайта на цветной фон.

### Экспорт

**Export Images** — сохраняет обработанные PNG в выбранную папку.

- **Rename** + **Prefix** — переименовать файлы с заданным префиксом и порядковым номером. Если выключено — сохраняются с исходными именами.

---

## Навигация во вьюпорте

- **Колесо мыши** — зум.
- **Перетаскивание мышью** — панорамирование. На вкладке Atlas перетаскивание внутри рамки Transform двигает содержимое, поэтому там панорама — средней кнопкой мыши или перетаскиванием за пределами рамки.
- Пока ничего не загружено, вьюпорт работает как зона загрузки: клик открывает выбор файлов, перетаскивание — загружает.

---

## Настройки

**Save Settings** / **Load Settings** — сохранение и загрузка всех параметров (keying, цвета, размеры, сетка, Transform) в `.json` файл. Удобно для повторяющихся задач с одинаковыми настройками.

## Сборка из исходников

Если нужно запустить без exe:

```
pip install PySide6 av opencv-python numpy
python main.py
```

Сборка в exe (Windows):

```
pip install pyinstaller
python build.py
```

Результат — `dist/AtlasConverter.exe`.

Сборка под macOS (запускать на маке — PyInstaller не кросс-компилирует):

```
pip3 install -r requirements.txt
python3 build_mac.py
```

Результат — `dist/AtlasConverter.app`. Иконка делается из `tear_icon.png` штатными `sips` и `iconutil`, бандл подписывается ad-hoc — этого хватает для запуска на своей машине.

Флаги:

- `--onefile` — один бинарник внутри `.app` (стартует медленнее, распаковывает ~150 МБ);
- `--universal2` — сборка под Intel и Apple Silicon сразу, работает только если Python и все колёса universal2;
- `--sign "Developer ID Application: Имя (TEAMID)"` — подпись для раздачи, добавляет hardened runtime и метку времени;
- `--dmg` — собрать ещё и `dist/AtlasConverter.dmg`.

Если скачанную сборку macOS блокирует: `xattr -dr com.apple.quarantine dist/AtlasConverter.app`.
